Drone target Specs :
- 150 Kg Payload
- Hexa-Copter configuration
- (optional) Coaxial-Copter Configuration
- 150 Km range

Processors and Core Specs
- FMU Processor: STM32F765 (32-bit Arm Cortex-M7, 216 MHz, 2MB Flash, 512KB RAM)
- IO Processor: STM32F100 (32-bit Arm Cortex-M3, 24 MHz, 8KB SRAM)
- Secure Element: SE050 for drone cryptographic authentication

On-Board Sensors
- Accel/Gyro 1: ICM-20649 (Hard Mounted)Accel/Gyro
- Accel/Gyro 2: ICM-42688P (Soft Mounted)Accel/Gyro
- Accel/Gyro 3: ICM-20602 or BMI088 (Soft Mounted)
- Magnetometer: BMM150
- Barometer: 2x BMP388 (on separate buses)

Electrical and Interfaces
- Max Input Voltage: 6V
- USB Power Input: 4.75V to 5.25V
- Servo Rail Input: 0V to 36V

Connectivity:
- 100Mbps Ethernet interface,
- 2x CAN bus,
- 5x UART,
- I2C,
- SPI,
- DSM/SBUS RC inputs
